# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Search the
[existing issues](https://github.com/reallysec/RST-AI-Copilot-for-Prometheus/issues)
before filing a new one to avoid duplicates. For new issues, file your bug or
feature request as a new issue using the provided templates.

For installation, configuration, and usage questions, start with the
[documentation](https://reallysec.com/en/docs/prometheus-ai-copilot).

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Commercial support

The Community Edition is provided as is, without a service level agreement.
For commercial support and the Professional and Enterprise editions, contact us
through [reallysec.com](https://reallysec.com).
