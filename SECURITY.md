# Security Policy

Anhui Reallysec Information Technology Ltd. ("Reallysec") takes the
security of its software seriously, including all repositories in
the [reallysec](https://github.com/reallysec) GitHub organization.

If you believe you have found a security vulnerability in RST AI Copilot
for Prometheus, please report it to us as described below.

## Reporting Security Issues

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Instead, email [security@reallysec.com](mailto:security@reallysec.com).

Please include the requested information listed below (as much as you can
provide) to help us better understand the nature and scope of the possible
issue:

- Type of issue (for example, injection, authentication bypass, information
  disclosure, server-side request forgery)
- Affected version and edition (Community, Professional, or Enterprise)
- Deployment method (delivery bundle, Docker Compose, other) and any special
  configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code, if possible
- Impact of the issue, including how an attacker might exploit it

Do not include credentials, license keys, or customer data in your report.

## Response Process

- We acknowledge receipt of your report within 3 business days.
- We provide an initial assessment within 10 business days.
- We keep you informed of our progress toward a fix.
- We credit reporters in the release notes, unless you prefer to remain
  anonymous.

## Disclosure Policy

We follow coordinated vulnerability disclosure. We ask that you allow us 90
days from the date of your report, or until a fix is released if sooner,
before disclosing the issue publicly.

## Supported Versions

Security fixes are provided for the latest minor release. Users of earlier
versions should upgrade to receive fixes.

| Version | Supported |
|---|---|
| 1.2.x | :white_check_mark: |
| < 1.2 | :x: |

## Preferred Languages

We prefer all communications to be in English or Chinese.
